# MillOS polish sweep — September 2026

Whole-codebase audit → adversarial verify → fix → hostile review, run as 16 disjoint
file lanes over the 303 live modules (dead modules per `validate:reachability` were
excluded), then a cross-lane integration pass. Raw per-lane records:
`_audit/polish-2026-09-25/` (ignored scratch: `lanes.json`, `followups.md`).

The pre-session working tree (a large uncommitted WIP) is preserved at
`refs/snapshots/pre-polish-20260923`. `git diff refs/snapshots/pre-polish-20260923`
shows only this session's edits. Nothing is committed or deployed.

## The headline game-logic fixes

- Trucks returned to the docks once per session: the arrival timer was never ticked.
- Every roller mill jammed ~4 minutes in: bran and middlings had no outlet.
- Machine wear never accumulated (sub-centi increments rounded away every tick).
- The global frame counter never advanced, so every throttled animation ran 2–4× fast.
- 12 of 16 achievements had no producer; the achievements panel read a frozen snapshot;
  tracking only ran on desktop.
- Incident replay, the machine inspector and several panels showed frozen snapshots.
- The 5,000-bag daily target was unreachable at any speed → 1,200 (≈85% of packer
  capacity at 180×).
- Fulfilling every order set the line setpoint to 0 and stopped the mill permanently.
- Deliberate stops (E-stop, drill, crossing waits) logged fake near-misses, sounded the
  horn and reset Days Safe.
- A recalled batch could be un-recalled in two steps and shipped.
- SCADA: idling a mill raised CRITICAL LOLO alarms that fed back into machine status;
  count-tag and HIHI alarms never cleared; 4h/24h trends returned the oldest data.
- AI: a tripped circuit breaker killed the strategic layer for the session; "Test
  Connection" hijacked the live client; "Gemini only"/"Local only" turned the AI off.
- Audio: loops started while muted never recovered; critter sounds ignored mute on a
  second AudioContext; the audio-reactive analyser never attached.
- Forklifts crabbed up to 58° on straights and snapped 125–180° at the route seam; rear
  wheels steered the wrong way; the receiving truck steered and articulated backwards.

## Decisions taken (2026-09-25 follow-up, delegated by Nell)

1. **Wear tuning → production clock.** `UnifiedGameTick` now feeds wear SIMULATED seconds
   (real delta x game speed). The `WEAR_CONFIG` rates were already per-game-second in
   scale: at 180x a roller mill first warns after ~8.5 real minutes (about one game day)
   and fails ~4 minutes later if ignored. Predictive alerts now derive their window from
   the wear rate (a mill at warning reads ~12.8 h game time) instead of a fixed 5-30 min.
   Consequence: at 1800x/10800x fast-forward, machines age 10x/60x faster too.
   `productionStore.tickMetrics` / `tickMachineMetrics` still use real seconds but have
   no caller.
2. **Sifter vibration units → one scale (mm/s velocity).** `SCADABridge` maps the sifter
   stroke-amplitude tag (mm, healthy band 4-9) onto the store's velocity scale: 1.0 at
   band centre, 3.5 at either alarm limit, ~4.5 at HiHi/LoLo. The offline simulation's
   running targets are now the SCADA baselines (silo 1.2, mill 1.6, sifter/packer 1.3
   mm/s at ~80% load), where mills previously drifted to ~3.8 and tripped the AI
   engine's 3 mm/s warning offline.
3. **Forklift spacing → wired, behaviour unchanged by default.** The three clearance
   sliders now drive `isPathClear` / `getForkliftsNearby`. Defaults are the controller's
   existing 2.5 / 4 / 5 m, so no deadlock check is needed for the default fleet; a v1
   persisted config holding exactly the old cosmetic 1.8 / 3 / 4 is migrated to the new
   defaults, and a user-moved config is kept. Speed-zone rate stays a planning value.
4. **Spatial engine audio → wired with inverse rolloff.** Forklifts and trucks register
   positions every 4th frame. Engines use Web Audio's inverse model (full within 10 m /
   15 m, 1/4 at 40 m) plus wall occlusion instead of the linear-to-zero falloff. From the
   overview camera, yard trucks sit at ~16% of their near level; forklifts INSIDE the
   building drop to ~0.02%, because the existing wall model (8% through the wall, then
   exterior decay over the 82 m to the camera) applies to them exactly as it already
   does to the factory hum. Before this, every engine played at full level from any
   camera. Not listened to.
5. **Village lamps → ground light pools.** Each of the 8 lamps gets an `ExteriorLampPool`
   (5.5 m) on the site-wide lamp driver; the lamp glass switches on that same level so a
   pool never lies under an unlit lamp. No punctual lights (no dusk recompile).
6. **Dead weight → removed.** The 15 unreferenced MP3s (~87 MB) are deleted from
   `public/`, `public/v0.20/` and `dist-archives/v0.20/` (manifest updated); the deploy
   staging copied every root MP3 into both v0.10 and v0.20, so the deployed artifact
   shrinks by ~170 MB. `Fanfare for Space.mp3` left the current build too: its only user
   was the uncalled `playVictoryFanfare` (the v0.20 archive keeps its own copy). 28
   uncalled `audioManager` methods and the state only they used are removed
   (~1.1k lines).
7. **OG image** re-rendered from the uncrewed build with `scripts/capture-og-image.mjs`
   (variant `scene-afternoon`: overview camera, 16:30, high tier), downscaled to 1200x630
   and quantised to 318 KB. The HUD variants were rejected: the first-run "AI
   Reflection" card covers the silos and the counters read 0 bags/h. og:image
   width/height and alt text updated in `index.html` and the staging root template.

8. **Deliberate behaviour changes to accept:** adaptive quality no longer climbs above
   the tier you chose; an agent's "modified" decision no longer runs the original
   recommendation; the forklift pickup at the shipping dead end now turns ~80° over the
   last 0.4 m instead of spinning 180° in one frame (not yet eyeballed in motion).
