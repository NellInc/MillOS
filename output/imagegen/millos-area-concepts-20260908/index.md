# MillOS concept reference atlas

Eight new two-view boards extend the original overview and production-floor concepts. Generated with the built-in image tool, using both original images as style references. These are visual targets, separate from runtime captures.

## Shared direction

Tactile miniature-world character; dark slender steel, teal enamel, champagne sifting cabinets, warm ivory sacks, silver spouting and quiet concrete. Warm directional daylight with cool fill, restrained cyan interaction cues and clear operational state colours. The mill remains uncrewed.
