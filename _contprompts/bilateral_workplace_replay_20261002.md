# Bilateral workplace replay implementation plan

## Outcome and authority

Nell requested a detailed plan and its implementation on 2 October 2026. The approved scope is local synthetic gameplay: matched operational replays, consequential choices, conduct-based debriefs, optional guidance, and candidate-bound automated acceptance. Existing anonymous fictional personnel remain. Real-worker data, human recruitment, external sends, publication, deployment and memory changes are excluded.

The testbed demonstrates practices independently. Coordinator-led operation, team consent and member governance retain the same minimum protections. A management label grants no production bonus. Real cooperative efficacy and human relationship quality require separate research.

## Pre-check and failure modes

The starting focused baseline passed 84 tests across the model, campaign, store and laboratory UI. The checkout has extensive concurrent changes. Owned edits are narrow; acceptance uses a copied candidate rather than building mutable shared source.

Three load-bearing risks:

1. Store-only rewind leaves vehicles in a different lifecycle. Capture component-owned controllers, interpolation phase, logistics timers, reservations and personnel clocks. Restore without creating arrival or departure events.
2. Rewind erases earned pay or recovery. Capture only an untouched discussion; require reviewed, settled recovery before another arm. Retain public run receipts and create a higher revision with fresh understanding, ballots and individual consent.
3. Forecasts appear to prove fair management improves output. Separate forecasts from observed dispatch. Record elapsed time, actual charter settings, costs, burden and repayment. Preserve shortfalls and differing horizons visibly.

## Scope and safeguards

The checkpoint is opaque session memory. It is never persisted, downloaded or accepted as an imported authority. The export contains bounded public summaries only. Rewinding changes local game progress, which the interface states before use. At most 12 run records are retained.

Synthetic role controls enact authored positions. They demonstrate consent mechanics and inspectable conduct, rather than establishing real consent, worker wellbeing or measured trust. A completed fair agreement may still miss delivery. The debrief retains both outcomes.

## Reversible implementation decisions

- Starting conditions and seeded maintenance randomness match. Frame-driven vehicle trajectories may differ with render timing; exact trajectory determinism is not claimed.
- Local replay uses fixed central-tick offline machine metrics. Simulated SCADA continues as a monitor but cannot overwrite the experiment's production state. Live or hybrid SCADA blocks replay.
- Camera placement, graphics preferences, credentials and user interface preferences are outside the operational checkpoint.
- The checkpoint is invalid after owner remount or material-session change. Reload requires a fresh experiment.
- Existing campaign decisions and material/dispatch authorities are reused. No new synthetic delivery fixture enters production code.
